## Presentation Controls
- **Arrow Keys / Spacebar**: Navigate slides
- **`O` / `Esc`**: Slide Overview Grid
- **`N`**: Toggle Bilingual Speaker Notes (EN / BM)
- **`T`**: Toggle Dark / Light Mode
- **`F`**: Fullscreen Mode
- **PDF Button**: Export clean 16:9 widescreen PDF slides
